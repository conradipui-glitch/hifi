# SEO-исследование: мастерская «Хай-Фай», Тобольск

Данные собраны движком [`yaai`](https://github.com/conradipui-glitch/yaai) (Wordstat + интент-разметка + планировщик страниц), две волны, 24 metered-запроса, 655 уникальных строк по двум регионам. Сырые результаты лежат в `conradipui-glitch/yaai`, путь `workspaces/hifi/`; здесь — выжимка и то, как она применена на сайте.

По Тюменской области: установка Windows — 1 735, сборка ПК — 1 670, восстановление данных — 668, оцифровка видеокассет — 76.

**Вывод.** Поисковый спрос на оцифровку в Тобольске практически нулевой: люди не ищут «оцифровку», они приходят с кассетой в руках или спрашивают «видеокассета». При этом владелец сознательно сузил сайт до оцифровки MiniDV и Digital8, поэтому спрос на Windows, сборку ПК и восстановление данных в текстах и разметке **не используется** — эти услуги на сайте не заявлены.

## Что изменено на сайте по итогам ревью

- `<title>`: «Оцифровка видеокассет MiniDV и Digital8 в Тобольске | Хай-Фай» — добавлено слово «видеокассет», по которому ищут люди.
- `H1`: «Оцифровываю домашние видеокассеты в Тобольске.» — город и формат в первом экране, без потери голоса владельца.
- `meta description`, Open Graph, `geo.region`, `geo.placename`, `canonical`.
- JSON-LD: `LocalBusiness` + `Service` с четырьмя реальными ценами + `FAQPage` на 7 вопросов; вопросы и ответы совпадают с видимым блоком FAQ.
- В гиде по кассетам явно сказано, что большие VHS не оцифровываются; для 8-мм кассет формат записи уточняется по маркировке.
- В калькуляторе добавлено пояснение: тариф считается по фактической длительности записи, точную длину мастер проверяет при осмотре.
- Телефон и адрес переведены с моноширинного набора на Manrope с табличными цифрами — ноль и восьмёрка больше не путаются.
- Добавлен пререндер: `npm run build` собирает статическую разметку через `react-dom/server` и вставляет её в `dist/index.html`, поэтому краулеры видят текст без выполнения JS. Проверка `scripts/check-seo.mjs` падает, если title/H1/FAQ/цены/телефон расходятся с ожиданиями.

3. Отзывы: просить у клиентов по оцифровке — «оцифровка кассет» в отзыве весит больше, чем страница.
4. Контент: отдельная страница-гайд «Как происходит оцифровка видеокассет» вырастет из главы 08, когда появится домен и хостинг с ЧПУ.
